# PKU SCALE Lab

Official website for PKU SCALE Lab, Scientific Computing And LEarning, at the Beijing International Center for Mathematical Research, Peking University.

This Jekyll site is designed for GitHub Pages. The main sections are Home, Research, People, Publications, News, Join Us, and Resources. Shared navigation and footer content live in _includes. Sitewide styles are in assets/css/site.css.
